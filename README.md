# Carrowmont Financial Independence Planner

A browser-based financial independence planning tool for Carrowmont.

The planner models a spending-based financial-independence target, compares it with projected invested assets and contributions, and shows how target age, inflation, investment return, contribution growth and planning withdrawal-rate assumptions affect the estimate.

## Live site

https://carrowmont.com/financial-independence/

## Files

- `index.html` — page structure and methodology content
- `styles.css` — planner styling
- `app.js` — user interface and rendering logic
- `core.js` — calculation engine
- `locale.js` — country and currency display logic

## Important

This is an educational planning tool. Results are illustrative and depend on user-entered assumptions. They are not financial, investment, tax or legal advice and do not guarantee sustainable future withdrawals.
